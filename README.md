<p>This is the fork of mkxp-z with the edits required for <b>Witness to Unity</b> and any other future projects of mine. It uses a mix of RGSS3 and 1 modes, alters some behaviours of Window rendering/interaction, and defaults to widescreen. I would <i>rather you not</i> use it yourself, as it may result in unforseen behaviours. Use the main fork.</p>
